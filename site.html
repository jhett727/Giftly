How a giveaway goes

You type /giveaway start, pick a prize and how long it runs, and Giftly posts it in the channel you choose. Members press the Enter button to join.

You decide who can join. Require a role, block a role, ask for a minimum account age, or give a role extra entries.

When time is up, Giftly picks winners at random and checks they're still in the server and still allowed to win. If someone never replies, /giveaway reroll draws a replacement.

Make it yours

Open /giveaway settings in your server to change the color, the button, the winner message, which role gets pinged, and who is allowed to run giveaways.

/giveaway start
Create a giveaway.
/giveaway end
Finish one early and draw.
/giveaway reroll
Draw again or replace a winner.
/giveaway edit
Change the prize, winners or end time.
/giveaway cancel
Stop one without a draw.
/giveaway list
See what's running.
